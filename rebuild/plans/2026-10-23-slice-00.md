## Review Focus

1. **Test project references an exe project**: `McpTime.Host.runtimeconfig.json` must be in the test output folder, otherwise `dotnet McpTime.Host.dll` does not start → task 4 checks this with its own test for the file.
2. **Trim analyzer against the generic host**: `Host.CreateApplicationBuilder` or `AddConsole` might report IL2026/IL3050 and turn the build red → task 1 builds with `-warnaserror`; a warning is reported, not suppressed.
3. **Empty assemblies make architecture rules vacuously true**: Core and Server have almost no types in slice 00 → task 3 also checks that every checked assembly was loaded (the rule runs against real assemblies, not against `null`).
4. **Verify in CI**: without `DiffEngine_Disabled=true`, Verify tries to start a diff tool → task 5 sets the variable in the workflow; `*.received.*` stays in `.gitignore`.
5. **`dotnet format` on Windows (CRLF)**: `.editorconfig` sets **no** `end_of_line`, `.gitattributes` normalizes to LF in the repo. Task 5 runs `dotnet format --verify-no-changes` locally (Windows) and in CI (Linux).
